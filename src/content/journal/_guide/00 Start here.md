# Start here

This folder is a guide for maintaining cjtech.dev from Obsidian. **Nothing in `_guide/` or `_templates/` is published.** Only notes inside `es/` and `en/` become pages.

## Your vault at a glance
```
journal/            ← this vault
├── _guide/         ← this guide (private)
├── _templates/     ← one template per kind of post (private)
├── es/             ← Spanish posts → cjtech.dev/es/journal/...
│   └── assets/     ← images for Spanish posts
└── en/             ← English posts → cjtech.dev/en/journal/...
    └── assets/     ← images for English posts
```

## The whole loop
1. **Pull** (get the latest changes)
2. **Write** a note in `es/` or `en/`
3. **Check** the properties
4. **Commit and push**
5. Wait about 1 minute → it's live
