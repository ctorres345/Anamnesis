# 05 · Two languages

Every post can exist in Spanish, English, or both.

## Post in both languages
1. Write the post in `es/` (for example `es/hollow-knight.md`).
2. Create the other version in `en/` (for example `en/hollow-knight.md`). The file names can be different.
3. Give both the **same `translationKey`**, for example `translationKey: hollow-knight`.
4. Publish.

Result: each version shows a link to the other ("Read in English" / "Leer en español"), and the ES/EN switch in the header jumps between them.

## Post in only one language
Just write one file. The page says "Only in English" or "Solo en español". That's fine.

## Rules
- Translate the text yourself (or with help), but keep the same `kind`, `date` and `game:` / `project:` / `video:` details in both.
- Interface words (menu, buttons) are already translated. You only write the post.
